# Sales Data Analysis Using Python

## Project Overview

This project analyzes sales data using Python to understand sales performance, product performance, regional sales, and profit.

## Objectives

* Load and inspect sales data using Pandas.
* Check missing values and duplicate records.
* Calculate total sales and total profit.
* Analyze sales by product and region.
* Analyze monthly sales trends.
* Create visualizations using Matplotlib.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* CSV Dataset

## Dataset Columns

* Order_ID
* Order_Date
* Product
* Category
* Region
* Quantity
* Sales
* Profit

## How to Run the Project

1. Install Python.

2. Install the required libraries:

   `python -m pip install pandas numpy matplotlib`

3. Keep `sales_analysis.py` and `sales_data.csv` in the same folder.

4. Run the following command:

   `python sales_analysis.py`
